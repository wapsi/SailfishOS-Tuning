# SailfishOS-Tuning
My Jolla SailfishOS fine scripts/patches/tunings. Most of the code has been created with assistance of AI.

## AutoScheduledDnD
How to activate and deactive Do-not-Disturb on specific time automatically.

## BtObexRestartHack
Car BT handsfree sometimes fails to connect my Sailfish phone and fails to sync contacts/call history (https://forum.sailfishos.org/t/bluetooth-car-connection-does-not-take-over-contacts-or-recently-called/33314/18), this is a workaround for that has been working for me quite nicely.

## DateTimeToTopBarPatch
This is an UI patch to get date & time on the Sailfish/Lipstick's Top Bar menu (the one that opens by sliding the top edge down).

## SmsToMatrix
This is a script that listens for incoming SMS messages, parse them and sends them to speficied Matrix room. It's handy when you're using SMS mainly for 2FA or similar one-way communication.
